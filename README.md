## 📋 Sobre o Projeto
 
O **Planejador Financeiro** é uma aplicação web que guia o usuário através de um formulário interativo de perguntas e respostas para criação de metas financeiras personalizadas. Com base nas respostas, a IA **Google Gemini** gera insights práticos para ajudar o usuário a alcançar seus objetivos.
 
Todos os dados são salvos no **localStorage** do navegador, permitindo que o usuário reveja e gerencie suas metas quando quiser, sem necessidade de conta ou login.
 
---
 
## ✨ Funcionalidades
 
- 📝 **Formulário guiado** — perguntas e respostas que levam à criação de metas financeiras
- 🤖 **Insights por IA** — geração de análises e sugestões personalizadas via Google Gemini
- 💾 **Histórico local** — metas salvas no localStorage para consulta futura
- 🗑️ **Gerenciamento de metas** — visualize e delete metas salvas quando quiser
- 🌗 **Tema claro/escuro** — alternância entre modo light e dark
